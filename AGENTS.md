# Project instructions

This repository is for Problem 6, the Utah Snowpack Map, and the deliverable is a single-file web app built incrementally according to the stages in `spec.md`.

## Folder layout

- `AGENTS.md` — project-wide instructions and file-placement rules.
- `spec.md` — requirements and behavior for the app.
- `prompts.md` — chronological log of prompts given by the user.
- `index.html` — the single-file web app.
- `00_planning/` — planning notes, sketches, and feature ideas.
- `01_data/` — data files used by the project.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

## File-placement rules

- Keep the app in the top-level `index.html`; do not add app files or begin implementation unless requested.
- Keep project requirements in `spec.md`, and project instructions in this file.
- Put supporting materials in the numbered folder that matches their purpose. Do not put planning, data, validation, or output artifacts at the repository root.
- Keep each numbered folder's `README.md` as a brief guide to the materials belonging there.
- **Log every prompt the user gives in `prompts.md`, in chronological order.** Preserve the prompt text and append new prompts rather than replacing earlier entries.

After each request, add an entry to prompts.md: what I asked, what you changed, and whether it worked.
After each request, commit all changes with a clear message.
